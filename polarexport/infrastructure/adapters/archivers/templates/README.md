# $TOOL_NAME night export

Generated by **$TOOL_NAME** v$TOOL_VERSION on $GENERATED_AT.

This archive holds night data pulled from the Polar AccessLink API and accumulated in a local
store over time — it was **not** produced by a single API call, so nights inside it may have been
captured weeks or months apart. It is meant to be attached to a prompt so an AI agent can analyse
sleep and recovery trends without consulting Polar's own API documentation.

Requested range: **$DATE_MIN → $DATE_MAX** ($NIGHT_COUNT nights with data).

## The 28-day retention window

Polar AccessLink v3 retains only the last 28 days of sleep, nightly-recharge and SleepWise data.
$HISTORY_WINDOW_NOTE

## Gaps

A "gap" is a requested date where **no** source returned any data at all — the device may not have
been worn, or the data has aged out of Polar's window and was never captured locally. Gap dates do
not appear in `nights.json`; only dates with at least one source of data do.

$GAPS_LIST

## `nights.json`

A single JSON envelope holding one entry per night with data, sorted ascending by date. Each night
has one block per source; a block is `null` when that source reported nothing for that night — see
"`null` vs `0`" below. Timestamps are ISO-8601 with the offset exactly as Polar reported it — do
not normalise them to UTC, the local offset is meaningful sleep context.

### `sleep`

| Field | Unit | Meaning |
|---|---|---|
| `sleep_start_time` / `sleep_end_time` | ISO-8601 datetime, local offset | Start/end of the tracked sleep period |
| `stages.light_seconds` / `deep_seconds` / `rem_seconds` / `unrecognized_seconds` | seconds | Time spent in each hypnogram stage |
| `continuity` | 1.0–5.0, higher is better | Sleep continuity score |
| `continuity_class` | 1–5, higher is better | See "Continuity class" below |
| `short_interruption_duration` / `long_interruption_duration` / `total_interruption_duration` | seconds | Time spent awake during the sleep period |
| `sleep_score` | 1–100 | Polar's overall sleep score |
| `sleep_charge` | 1–6, higher is better | How well this sleep recharged the body |
| `sleep_goal` | seconds | The user's configured sleep goal |
| `sleep_rating` | integer, self-reported | The user's own subjective rating, if logged (Polar does not publish the exact scale) |
| `sleep_cycles` | count | Number of sleep cycles detected |
| `group_duration_score` / `group_solidity_score` / `group_regeneration_score` | 0–100, higher is better | Sub-scores that combine into `sleep_score` |
| `hypnogram` | `"HH:MM"` (device-local time) → stage code | One observation per hypnogram entry; see "Hypnogram stage codes" below |
| `device_id` | string | Identifier of the device that captured the night |

### `recharge` (Nightly Recharge)

| Field | Unit | Meaning |
|---|---|---|
| `nightly_recharge_status` | 1–6, higher is better | See "Nightly Recharge status" below |
| `ans_charge` | signed float, higher is better | Change in autonomic nervous system charge relative to baseline; can be negative |
| `ans_charge_status` | integer | Polar's internal status code paired with `ans_charge` |
| `heart_rate_avg` | bpm | Average heart rate during the night |
| `heart_rate_variability_avg` | ms | Average heart rate variability during the night |
| `beat_to_beat_avg` | ms | Average beat-to-beat interval |
| `breathing_rate_avg` | breaths/min | Average breathing rate during the night |

### `skin_temperature`

| Field | Unit | Meaning |
|---|---|---|
| `sleep_start` / `sleep_end` | ISO-8601 datetime, local offset | Sleep period the temperature samples belong to |
| `samples[].time` / `samples[].deviation` | ISO-8601 datetime / °C | Per-sample deviation from the user's baseline skin temperature |
| `deviation` | °C | Deviation from baseline for the whole night |

### `sleepwise`

| Field | Unit | Meaning |
|---|---|---|
| `alertness_hourly[].hour` / `alertness_hourly[].alertness_level` | hour of day (0–23) / label | Predicted alertness level for that hour |
| `sleep_time` / `wake_time` | ISO-8601 datetime, local offset | Predicted sleep and wake times |
| `bedtime_window_start` / `bedtime_window_end` | ISO-8601 datetime, local offset | Polar's recommended bedtime window |

### `heart_rate` (continuous heart rate)

| Field | Unit | Meaning |
|---|---|---|
| `samples[].time` / `samples[].heart_rate` | ISO-8601 datetime / bpm | Heart rate sample; clipped to the sleep window when sleep data is present for the same night |

## `null` vs `0`

`null` means the device or Polar did not report that field for the night — it is not the same as a
measured value of `0`. Do not treat a `null` field as zero in any analysis.

## `raw/`

When this archive was built with raw payloads included, `raw/<source>/<date>.json` holds the
untouched Polar API response for that source and date, exactly as AccessLink returned it. Use it
when a field you need is missing from `nights.json` — the raw payload is the ground truth.

## `manifest.json`

A machine-readable summary of this export: tool version, requested date range, per-source
availability, and any gaps. It repeats information already in this README in a form meant for
automated consumers rather than for a human or AI reading the archive directly.
